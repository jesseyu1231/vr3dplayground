Wending Pavilion

Curator's Studio — a desktop & VR studio for curating Chinese-art exhibitions in 3D.

This guide walks through every part of the studio: how to launch it, move around, place and arrange artworks, light the room, talk to the AI docent, and present the result in VR. New here? Start with installing, then read the studio at a glance.

Screens in this guide are drawn as labelled diagrams. Where you see a dashed “Add screenshot” box, you can drop your own PNG next to this file (e.g. screenshots/overview.png) and it will appear automatically.

1Install & run the app

The studio ships as a desktop app for macOS (Universal — Intel & Apple Silicon) and Windows (64-bit). You can also run it in a browser during development with npm start.

These builds are unsigned. They are not code-signed with an Apple Developer ID or a Windows certificate, so the first time you open the app your operating system will show a security warning. This is expected — the steps below tell your computer to trust it. You only need to do this once.
macOS — do this first, on every Mac. After copying the app to Applications, open Terminal and run the command below to clear Apple’s quarantine flag. Skip it and macOS will block the unsigned app or call it “damaged and can’t be opened.” xattr -dr com.apple.quarantine "/Applications/3D AI Environment.app"

🍎 macOS (universal .dmg)

  1. Open 3D AI Environment-1.0.0-universal.dmg and drag 3D AI Environment into your Applications folder.
  2. Clear the quarantine flag — required on every Mac. Open Terminal and run: xattr -dr com.apple.quarantine "/Applications/3D AI Environment.app"
  3. Now open the app (double-click). If it’s ever still blocked, right-click → Open → Open, or use System Settings → Privacy & Security → Open Anyway.
The universal build runs natively on both Intel and Apple Silicon Macs — no Rosetta needed.

🪟 Windows (.exe installer)

  1. Run 3D AI Environment Setup 1.0.0.exe.
  2. Windows SmartScreen may say “Windows protected your PC.” Click More info, then Run anyway.
  3. If your antivirus flags the unsigned installer, choose Allow / Keep.
  4. Follow the installer — you can pick the install folder and create Desktop / Start-menu shortcuts.
Prefer not to install? Ask for the portable (zipped) build — it runs straight from a folder with no installer.
Want builds without these warnings? That requires paid code-signing certificates (an Apple Developer ID + notarization for macOS, and an Authenticode certificate for Windows). The app and its source are unchanged either way.

2The studio at a glance

When the studio opens you’re standing in a white-cube gallery with a garden beyond the moon-gate and an AI docent in the room. Everything you need sits around the edges of the screen.

  1. Title & status badge — the room name plus your XR (VR) support status and how many people are connected.
  2. Toolbar — every creation and editing tool (full reference below).
  3. Transform modes — switch the gizmo between Move, Rotate and Scale (T/R/S).
  4. Scene Items panel — a live list of everything in the room, grouped into a Defaults folder, your imported Objects, and User Lights.
  5. The 3D viewport & docent — click an artwork to select it; drag to look around (see Moving around).
  6. Chat panel — talk to the AI docent.
  7. Shortcuts hint — always-on cheat-sheet for keys and the fly-cam.

3Moving around the scene

There are two ways to get around: orbit (great for inspecting a single piece) and the fly-cam (great for walking the room like a first-person game).

Fly-cam — “walk” the gallery (Unreal-style)

Hold the right mouse button to enter the fly-cam, then steer with the keyboard — exactly like a first-person editor. Release the button to go back to orbiting.

The fly-cam passes straight through walls and objects — no collision — so you can move freely anywhere, even outside into the garden. Your normal editing shortcuts are paused while you hold the right button, so S won’t switch to Scale mid-flight.

4Select & transform objects

Click any object (or pick it in the Scene Items panel) to select it. A gizmo appears so you can move, rotate or scale it.

ModeKeyHow to use
MoveTDrag the colored arrows to slide along one axis.
RotateRDrag the rings to spin around an axis.
ScaleSDrag a handle to resize along that axis.
Uniform (locked-ratio) scaling: hold Shift while dragging any scale handle — the object grows or shrinks evenly on all three axes, keeping its proportions, no matter which handle you grab.

5Adding objects

Click 📦 Import 3D to open the import window. It has two tabs:

Primitives

Quick building blocks — pick a shape and a color, then Add to Scene:

■ Cube ● Sphere ▮ Cylinder ▲ Cone ◯ Torus

Use the Color swatch to tint the new shape.

Upload a model

Switch to Upload File and choose a .glb or .gltf file (drag-drop or click). It’s added to the room and appears under Objects in the Scene Items panel.

Polygon budget: a small badge warns you as the scene’s triangle count approaches the Meta Quest limit, so your exhibition stays smooth in VR.

6Lights & lighting

Room lighting presets

Click ☀ Lighting to cycle through curated presets (e.g. Gallery Daylight) that change the overall mood and time-of-day in one click.

Add your own lights

  • 💡 Add Spotlight — a directional light you can position and aim.
  • 🔆 Add Lamp — a point light that glows in every direction.

Select a light to open the Light Properties panel:

💡 Light Properties
Color
Intensity 1.0
Remove Light

Adjust Color and Intensity, or click Remove Light to delete it.

The room’s built-in default lights (Ambient, Sun, Skylight, Rim, Fill) live in the Defaults folder, where each can be dimmed, removed or restored.

7Scene Items & the Defaults folder

Click 📋 Scene Items to open a live list of everything in the room. It has three parts:

  1. 📁 Defaults folder — the room’s built-in pieces: Gallery (the white-cube architecture), Garden (the literati garden), Robot Docent, and the default Lights. Click the header to collapse/expand it.
  2. Remove / restore all — the folder’s ✖ hides every default at once; it turns into ➕ to bring them all back. The count (e.g. 8/8) shows how many are currently in the scene.
  3. Per-item controls — 🔍 focuses the camera on that item; ✖ removes it; a removed item greys out and shows ➕ to restore it.
Removing a default only hides it — nothing is destroyed, so Restore (or ⌘Z) brings it back exactly as it was. Clicking an item’s name (or 🔍) flies the camera to frame it.

Below the folder, Objects lists everything you’ve imported and User Lights lists lights you’ve added — click any row to select it, or 🔍 to focus it.

8The AI docent & chat

The studio includes an AI docent (the robot in the room) you can talk to about the exhibition.

1
Add your AI key. Click 🔑 AI Key, paste your POE API key, optionally set a bot name, and Save. This enables the docent’s replies.
2
Open chat. Click 💬 Chat to toggle the chat panel (bottom-right).
3
Talk. Type a message and press Send (or Enter). The docent answers and the speech bubble plays an idle/talking animation.

Use your own character

Click 🤖 Change Docent to upload your own rigged character (a Mixamo-style .glb). It replaces the default robot. A ↩️ Reset Docent button appears to restore the original.

Chat replies require a valid POE API key. Without one, you can still type messages, but the docent won’t respond.

10Working together (multiplayer)

The studio is collaborative — several people can curate the same room at once.

  • Click Name (top-left) to set the display name others see.
  • The badge shows how many people are connected.
  • You’ll see other curators’ cursors moving in real time, and changes sync between everyone.

11VR mode (Meta Quest)

On a WebXR headset (e.g. Meta Quest), an Enter VR button appears. The XR status in the top-left badge tells you whether VR is ready.

In VRHow
Move aroundLeft thumbstick to glide; right thumbstick to snap-turn.
Point & click UIThe right controller shoots a laser — aim and pull the trigger.
Chat panelLives on your left wrist — buttons for Mic, Keys and Send.
Talk to typeTap Mic and speak — on-device speech-to-text turns it into a message (no internet needed for transcription).
Type manuallyTap Keys for a floating keyboard and point-click letters.
Leave VRPress B on the controller (confirm), or use the on-screen Exit VR prompt.
VR locomotion is collision-free, just like the desktop fly-cam — you can glide anywhere in the gallery and garden.
WebXR needs a secure context. On a headset, open the app over https:// (or localhost); the badge will tell you if HTTPS is required.

12Developer tools

Click 🛠️ Dev Tools for a panel aimed at tuning and debugging (most curators won’t need this):

  • Character Animation — force the docent to “talk”, trigger a 3-second talk burst, watch the talk timer.
  • Bone Tweaks — nudge a selected bone’s idle X/Y/Z rotation, and log the tweaks.
  • Mixamo Bones — list the tracked bones / dump all node names of an uploaded character.
  • Scene Info — log the scene graph, see the live object count and FPS.
